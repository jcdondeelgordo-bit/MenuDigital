# Corte X Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Darle al cajero un botón en `cuadre.html` para generar, en cualquier momento del día, un corte impreso/PDF de lo vendido hasta ese instante (acumulado desde el inicio del día), quedando registrado oficialmente en el Sheet quién lo generó y a qué hora.

**Architecture:** Nueva acción de solo-agregar-y-leer `generar_corte_x` en el Apps Script de Inventario (`Code.gs`), que lee la hoja `Ventas` del Sheet del Menú Digital (filtrando `Estado=Pagado` y `Hora <= ahora`), agrupa por producto/método de pago/canal usando una función pura testeable con Node, y agrega una fila resumen a una hoja nueva `Cortes_X`. El frontend (`cuadre.html`) agrega una pestaña nueva con selector de cajero (catálogo Empleados, con caída a texto libre), botón de generar, y botón de imprimir reutilizando el patrón `@media print` ya usado en `caja.html`.

**Tech Stack:** Google Apps Script (backend, JavaScript ES5-compatible), HTML/JS vanilla (frontend, sin frameworks), Node.js (solo para el test de la función de agregación).

## Global Constraints

- El Sheet del Menú (`MENU_SHEET_ID = '1WIltJ3wSxGu9VQDGmnj5Lx9uXqUfWjA7Q9aKcZK32ak'`) es DISTINTO del Sheet de Inventario (`SHEET_ID`) — Corte X lee ventas del primero, pero la hoja `Cortes_X` que registra el corte se crea en el segundo (mismo Sheet donde ya viven `Cuadre_Caja`/`Gastos_JC`).
- Encabezados reales confirmados por el usuario en la hoja `Ventas` del Sheet del Menú: `Fecha, Hora, Código_Producto, Producto, Cantidad, Precio_Unitario, Total, Registrado_Por, Estado, Tipo_Pedido, ID_Pedido, Observacion, Mesa, Mesero, Estado_Cocina, Metodo_Pago`. Usar `indexOf('NombreColumna')` para ubicar columnas, nunca posiciones fijas — mismo criterio que ya usa `calcularResumenCaja_` en `Code.gs:417-484`.
- Solo cuenta como venta un `Estado === 'Pagado'` — pedidos pendientes de pago NO entran al corte.
- Este proyecto no usa librerías de generación de PDF — "PDF" = imprimir con el navegador (`window.print()`), igual que los recibos de `caja.html`.
- Cualquier edición a `Code.gs` (el archivo local en `E:\Descargas\MENU\DONDE EL GORDO\Code.gs`) debe pegarse a mano en el editor de Apps Script en vivo por el usuario y publicarse como nueva versión — no hay despliegue automático de ese proyecto. - `generar_corte_x` ESCRIBE una fila cada vez que se llama (agrega a `Cortes_X`) — nunca debe dispararse automáticamente al cambiar de pestaña o cargar la página, solo por tap explícito del botón "Generar Corte X".

function round2_(n) { return Math.round(n * 100) / 100; }

function agruparVentasParaCorteX_(filas, idx) {
  const porProducto = {};
  const porMetodo = { Efectivo: 0, Nequi: 0, Tarjeta: 0 };
  const porCanal = {};
  let totalVenta = 0;
  filas.forEach(function (row) {
    const producto = (row[idx.producto] || '').toString().trim();
    if (!producto) return;
    const cantidad = parseFloat(row[idx.cantidad]) || 0;
    const total = parseFloat(row[idx.total]) || 0;
    if (!porProducto[producto]) porProducto[producto] = { cantidad: 0, total: 0 };
    porProducto[producto].cantidad += cantidad;
    porProducto[producto].total += total;
    totalVenta += total;
    const metodo = (row[idx.metodoPago] || '').toString().trim();
    if (metodo === 'Nequi') porMetodo.Nequi += total;
    else if (metodo === 'Tarjeta') porMetodo.Tarjeta += total;
    else porMetodo.Efectivo += total;
    const canal = (row[idx.tipoPedido] || '').toString().trim() || 'sin_canal';
    porCanal[canal] = (porCanal[canal] || 0) + total;
  });
  Object.keys(porProducto).forEach(function (k) {
    porProducto[k].cantidad = round2_(porProducto[k].cantidad);
    porProducto[k].total = round2_(porProducto[k].total);
  });
  Object.keys(porMetodo).forEach(function (k) { porMetodo[k] = round2_(porMetodo[k]); });
  Object.keys(porCanal).forEach(function (k) { porCanal[k] = round2_(porCanal[k]); });
  return { porProducto: porProducto, porMetodo: porMetodo, porCanal: porCanal, totalVenta: round2_(totalVenta) };
}
